# Citybikes PWA

A bike share app to rule them all. It's built with the following in mind:

* Fast - Simple - Reliable
* Respects your privacy
* It is not spyware
* Fun to use

Check the running version over at https://app.citybik.es

Think it could be better? Help us!

## Development

```bash
npm i
npm run dev
```
